# Next.js E-commerce Starter (Tailwind + GSAP + Razorpay)

## Quick start

1. Copy the project and run `npm install`
2. Create `.env.local` (see `.env.local.example`) and add your Razorpay test keys.
3. Run `npm run dev` and open http://localhost:3000

## Notes
- This is a demo starter. In production you MUST save orders to a database, validate totals server-side, and secure secrets.
- To deploy to Vercel, add environment variables in the Vercel dashboard.
